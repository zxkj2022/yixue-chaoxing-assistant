# 超星学习通易学助手

为兼容的学习通页面提供学习辅助，支持视频、文档、章节测验、作业和考试页面的部分自动操作。

[安装最新版脚本](https://raw.githubusercontent.com/zxkj2022/yixue-chaoxing-assistant/main/dist/%E6%98%93%E5%AD%A6%E8%B6%85%E6%98%9F%E5%AD%A6%E4%B9%A0%E9%80%9A%E5%8A%A9%E6%89%8B.user.js) · [免责声明与数据传输说明](免责声明.md)

## 功能介绍

- 视频、文档等学习页面辅助操作。
- 查询单选、多选、判断和填空题的参考答案，在兼容页面中展示或辅助填写。
- 可选 AI 参考答案，实际可用性取决于所用服务与账户权限。
- 显示积分、会员每日剩余额度和到期时间，支持免费刷新额度。
- 圆角 iOS 风格章节控制台，集中管理任务开关、配置、进度与日志；支持窄屏布局。
- 悬浮窗和脚本菜单设置。
- 题目采集默认关闭，需要用户主动授权开启。

## 安装与使用

1. 在浏览器中安装支持用户脚本的管理器。
2. 点击上方「安装最新版脚本」，按提示完成安装。更新时请替换旧版，只启用一份。
3. 打开学习通课程页，首次使用可选择「随机生成 Token」，进入功能选择面板。
4. 点击「刷章节」进入任务控制台，在这里设置任务开关、视频倍速和最低正确率，查看进度与日志，再按需启动。
5. 随机 Token 仅保存在本机，不连接题库；视频、文档功能可先使用。需要答题时，选择「连接题库」获取题库 Token，再通过「手动填写 Token」或面板输入框保存。
6. 使用前请确认所在学校、课程及平台允许相关操作。

默认配套题库网站：[tk.sanzwk.com](https://tk.sanzwk.com)。脚本本身免费，题目查询及 AI 服务可能收费，具体以服务方说明为准。

## 使用提示

- 参考答案请结合教材人工核对，不承诺固定正确率或考试成绩。
- 额度可通过悬浮窗「刷新额度（免费）」或脚本菜单手动刷新；充值和账户信息请到题库网站查看。
- 遇到网络、权限、额度或限流提示时，请先处理对应问题，再继续使用。
- 页面变化、浏览器限制和网络状态可能影响运行；不保证所有学校页面均兼容或始终自动执行。
- Token 属于个人凭据，请勿放入截图、公开配置或分享给他人。
