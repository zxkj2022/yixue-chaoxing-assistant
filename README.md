## 功能

- 超星学习通兼容页面的视频、文档、直播及章节任务辅助。
- 单选、多选、判断和填空题的参考答案查询；兼容页面可辅助填写，答案请人工核对。
- 知到智慧树兼容课程页面的视频播放、目录切换与当前练习查询辅助。
- 可选 AI 参考答案，是否可用及实际消耗取决于题库服务和账户权限。
- 显示积分、会员等级、每日剩余额度及到期时间；刷新额度不收费。
- 课程任务控制台提供任务开关、倍速、进度、日志、启动和停止，适配手机与桌面页面。
- 支持运行时保持亮屏；浏览器、系统和平台限制仍可能导致后台或锁屏后暂停。
- 自动检查脚本更新，也可点击“检查更新”重试；新版安装由脚本管理器处理。

## 使用

1. 安装支持用户脚本的管理器，再点击“安装最新版”。更新后只保留一份易学助手。
2. 打开课程页面。首次使用可选择“随机生成 Token”进入本地模式，先使用视频、文档等功能。
3. 需要参考答案时，前往[题库网站](https://tk.sanzwk.com)获取个人 API Token，通过“设置搜题 Token”或面板保存。
4. 按需开启任务并点击“开始运行”，通过进度和日志核对结果；需要中止时点击“停止运行”。

**禁止与其他网课脚本同时运行。** 请检查脚本猫、油猴、暴力猴等管理器，停用其他同类脚本及多余的易学助手。检测到可识别的冲突时，脚本会阻止启动或停止当前任务，处理后刷新页面。

**有任何使用疑问可以加入 QQ 群反馈，QQ群：952042950。**

## 使用提示

- 参考答案可能有误，请结合课程材料核对，不承诺固定正确率或考试成绩。
- 章节测验只有在开启自动提交并达到所设填写比例时才尝试提交；填写比例不代表实际得分。作业、考试的最终交卷由使用者确认。
- 连接题库后，脚本会发送查询所需的题目内容；兼容页面还会自动采集题目和可确认的公开或已批改正确答案。具体范围请先阅读[使用与数据说明](https://github.com/zxkj2022/yixue-chaoxing-assistant/blob/main/%E5%85%8D%E8%B4%A3%E5%A3%B0%E6%98%8E.md)。
- 遇到权限、额度、限流或网络提示时，处理对应问题后再继续；请勿频繁重复付费查询。
- Token 属于个人凭据，请勿公开、放入截图或分享给他人。
